# Outreach playbooks

Templates for warm, low-friction outreach. **Target lists and per-target status live in the Notion Outreach CRM**, never in this folder.

| File | Audience | Goal |
|---|---|---|
| [`cozy-streamer-pack.md`](./cozy-streamer-pack.md) | Mid-tier Twitch variety streamers, VTubers | Free stream-safe music + visual overlay pack → recurring on-stream attribution |
| [`itch-io-game-jam.md`](./itch-io-game-jam.md) | Indie game devs on Itch.io, cozy game jam participants | Free game-safe asset bundle → in-game credits + EPK link |

## Status conventions (mirror the Notion Outreach CRM)

- **Not Contacted** — researched, in CRM, no message sent
- **Pitched** — first outreach sent
- **Followed Up** — second touch (only after 7+ days, only if no reply)
- **Partnered** — agreement in place, tracks delivered
- **Declined / No Fit** — politely closed, do not re-contact for 6 months

## Tone

- **Warm, never cold-spam.** Every pitch references something specific about the recipient — a stream title, a recent jam entry, a track they used last week.
- **Lead with the gift.** The first message offers value. Asks come later (if at all).
- **Short.** If it doesn't fit in a Twitch DM, it's too long.
- **One personal note minimum.** Mass DMs are an instant-fail for this audience.
