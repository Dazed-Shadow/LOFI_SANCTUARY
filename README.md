# LOFI_SANCTUARY

> *A cozy gamer sanctuary — original lo-fi tracks paired with seamless pixel-art visuals, packaged for indie game devs and Twitch streamers.*

This repository is the **true home** of the LOFI_SANCTUARY campaign. The Notion workspace `MR_C · LOFI_SANCTUARY` is the **command center** for day-to-day updates, asset tracking, and outreach status.

## What this is

Weaponize a library of original lo-fi music into a multi-platform creative campaign:
- Long-form ambient loops for YouTube
- Short-form "fake cozy dev log" hooks for TikTok / Shorts
- Audio-reactive visualizers
- Stream-safe music packs for Twitch variety streamers
- Asset bundles for indie devs participating in Itch.io cozy game jams

Target audience: the **Cozy Gaming** subculture — fans of Stardew Valley, Animal Crossing, Coffee Talk, Unpacking — plus mid-tier variety streamers and indie devs.
